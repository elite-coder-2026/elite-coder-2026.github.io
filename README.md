## About This Site

A single hand-written HTML page: no frameworks, no build step.

* **Sections:** intro, projects with real screenshots of each app running, approach, journey, tech, and contact.
* **Search-ready:** page title and description, keywords, canonical URL, OpenGraph tags, `schema.org` Person data, `robots.txt` and `sitemap.xml`.
* **Responsive:** works on phones, tablets and desktops.

## Layout

```text
.
├── index.html          # The portfolio page (HTML + inline CSS)
├── portfolio-images/   # Screenshots of each project running
├── robots.txt          # Lets search engines crawl the site
├── sitemap.xml         # Tells search engines which pages exist
└── README.md
```
