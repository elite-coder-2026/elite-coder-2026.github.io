Approach

Four decades of shipping software comes down to a few habits that keep codebases healthy as they grow.

Raw SQL, no ORM

Parameterized queries I can read, tune and explain. The database enforces the rules with constraints and triggers.

Strict layers

Routes, controllers, services and data access each do one job, so changes stay small and bugs stay findable.

Code people can read

Clear names, small functions and honest comments, written for the next developer, not for the compiler.
